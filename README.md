## Overview

Claude Planning Tool gives developers and technical users a structured way to build prompts for Claude Code. Rather than writing each planning instruction from scratch, choose a Claude model, specify the application or project focus, and select the required effort level. The tool then creates a prompt that can be copied into an existing workflow.

This lightweight browser utility includes an offline planning engine and a focused interface for repeatable prompt creation. It can be used for development, productivity, and automation planning without setting up a separate command-line application.

- Choose from the available Claude models.
- Describe the focus of an application or project.
- Set the effort level used for planning.
- Generate prompts formatted for direct use with Claude Code.
- Send generated prompts to the clipboard.

## How to Use

1. Open Claude Planning Tool in a browser.
2. Pick the Claude model for the task.
3. Enter the application or project focus.
4. Select the desired effort level.
5. Create the planning prompt.
6. Copy the generated text to the clipboard.
7. Insert the prompt into your Claude Code workflow.

Once the tool is available locally in the browser, its planning engine can prepare prompts without an active network connection.

## Frequently Asked Questions

### Who can use Claude Planning Tool?

The tool is designed for people working with Claude Code who want a consistent, structured method for preparing project prompts.

### Are multiple Claude models available?

Yes. Selecting a Claude model is one of the steps in the prompt planning process.

### Is offline use supported?

Yes. The planning engine works offline. The hosted build and automatic update checks may still require an internet connection.

### Where do I change the planning options?

Set the model, application focus, and effort level within the tool's interface.

### How do I save a generated prompt to the clipboard?

Generate the prompt and use the built-in clipboard action. The copied result can then be placed into Claude Code or another workflow.

### What if the application fails to open?

Make sure you are using an up-to-date browser on Windows. If you are running a local copy, confirm that the repository downloaded successfully and open the main HTML file in the browser.

### How does the tool receive updates?

Claude Planning Tool performs automatic update checks. You can also return to the published build to access the latest available version.
